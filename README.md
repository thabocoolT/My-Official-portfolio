# Personal Portfolio Website

This repository contains the source code for my personal portfolio website. I built it to showcase my projects, technical skills, and experience while also challenging myself to create a modern user interface using only HTML, CSS, and JavaScript.
Rather than using a template or frontend framework, I wanted to understand how different UI effects work by building them myself. This includes the animated background, glassmorphism design, typing animation, custom carousels, theme switching, and responsive layouts.

## Live Demo
🔗 https://thabo-motau-portfolio.netlify.app/

##Features
- Responsive design for desktop, tablet, and mobile devices
- Light and dark mode
- Animated hero section with typing effect
- Glassmorphism-inspired user interface
- Interactive skills carousel
- Projects section with technology tags and project status
- Contact form powered by Formspree
- Scroll animations throughout the website
- Downloadable CV
- Links to GitHub and LinkedIn

## Built With
- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome
- Devicon
- Google Fonts
- Formspree

This project helped me gain a much better understanding of frontend development beyond the basics taught at university.

Some of the things I learned include:

- Writing cleaner and more maintainable CSS
- Building responsive layouts without relying on frameworks
- Creating reusable JavaScript components
- Implementing theme switching with Local Storage
- Working with animations and transitions
- Organising a real project structure
- Using Git and GitHub throughout development
