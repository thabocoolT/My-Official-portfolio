# Design Documentation

## Purpose

The primary goal of this portfolio was to create a modern and professional website that represents me as a software developer while showcasing my technical skills, projects, and experience.

Rather than using a pre-built template, I chose to design and develop every section myself. This allowed me to better understand responsive web design, user experience, animations, and frontend development principles.

---

# Design Goals

The website was designed around the following objectives:

- Create a strong first impression for recruiters.
- Maintain a clean and easy-to-navigate interface.
- Ensure compatibility across desktop, tablet, and mobile devices.
- Highlight projects without overwhelming the visitor.
- Demonstrate frontend development skills through custom UI components.

---

# Design Inspiration

The overall visual style follows a futuristic synthwave-inspired theme.

The interface combines:

- Dark backgrounds
- Glassmorphism
- Neon accent colours
- Smooth animations
- Soft glowing effects

This theme was chosen because it gives the portfolio a modern appearance while helping it stand out from traditional portfolio websites.

---

# Colour Palette

| Colour | Purpose |
|---------|----------|
| Dark Navy | Main background |
| Purple | Primary accent |
| Cyan | Interactive highlights |
| White | Text |
| Light Gray | Secondary text |

The colour palette was selected to provide high contrast while maintaining readability.

---

# Typography

## Font

Poppins

Reasons for choosing Poppins:

- Modern appearance
- Excellent readability
- Works well across different screen sizes
- Commonly used in professional websites

---

# Layout

The portfolio follows a single-page layout.

Sections include:

1. Hero
2. About
3. Skills
4. Projects
5. Contact

This allows visitors to quickly navigate through the website without loading multiple pages.

---

# User Experience

Several design decisions were made to improve user experience.

## Hero Section

The landing section introduces visitors with:

- Name
- Developer roles
- Profile picture
- Social links
- Download CV button

## Skills

Skills are displayed using an animated carousel instead of a long list.

This reduces clutter while encouraging interaction.

## Projects

Projects are displayed as cards containing:

- Description
- Technologies used
- Status
- GitHub link
- Live Demo link

## Contact

A simple contact form allows recruiters to send messages directly without leaving the website.

---

# Responsiveness

The website was designed to work across multiple screen sizes.

Breakpoints include:

- 1200px
- 992px
- 768px
- 480px
- 360px

Layouts automatically adjust using Flexbox and CSS Grid.
